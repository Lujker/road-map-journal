# Optional templates

Use only after consent to create the relevant file. Match the project's language, naming, status rules and format; placeholders are not facts.

## Roadmap

```markdown
# Roadmap

## Current items
- ID — Title | Status | Acceptance criterion | Details: <relative path>

## Next work
1. ID — Remaining work and dependency or blocker, if known.
```

## Item or journal entry

```markdown
# ID — Title
Status: OPEN
Acceptance: [agreed observable outcome]

## Current state
[What is known; distinguish implementation, evidence, and remaining work.]

## Journal
- [Date, if known] Decision or finding; rationale and source.
- Evidence: [actual check, outcome, scope, and executor, or explicitly not checked].
- Remaining: [unfinished acceptance and blockers].
```

## Handoff

```markdown
# Current handoff
Decision: [current approved direction]
Next step: [specific action; state if explicit resume is required]
Remaining acceptance: [checks or approval still needed]
Open questions: [decisions and owners if known]
History: [link to prior decisions]
```
