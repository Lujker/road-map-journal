# Scenarios

- **Status question:** Read the current item and evidence; report what is recorded and what is not verified. Do not modify files.
- **No roadmap:** Propose a location and compact outline; create only after the user understands and approves the proposal.
- **Existing plan elsewhere:** Use its established location and language. Ask before migration or creating a competing plan.
- **Resume one item:** Confirm the selected scope against the latest directive. Work only on that item; record any remaining acceptance instead of starting the next one.
- **Tests pass, live check outstanding:** Record the real test result and mark the item PARTIAL or equivalent if live acceptance is required. Do not imply that the live check passed.
- **Decision changed:** Update authorized current instructions, retain the earlier decision as history, and flag contradictions outside the approved edit scope.
- **Multiple repositories:** Compare each plan with its own Git and, when needed and authorized, live evidence. Preserve unrelated changes, report inaccessible sources, and do not publish without authorization.
- **Future requirement recorded:** Add it where authorized without treating it as permission to implement or reorder unrelated work.
