A later model-free probe with shell features enabled also omitted `tools`, so this does **not** isolate the effect of disabling them. This is preliminary evidence that a **narrower text-only comparison** can be built without exposing an agent tool surface: the actual synthetic plan would be supplied as user text and the skill text explicitly supplied as instructions. That is not the originally planned agent-driven file-discovery test, native skill activation, or equivalent to a verified live subscription session. The live OpenAI/Codex path, credential boundary and actual outgoing tool list/instruction content remain unverified.
